## 如何启动

首次获取项目，按 [资源放置说明](资源放置说明.md) 准备本地数据与模型。
[2026年10月27日资源包](https://github.com/jrh010806/offline-dewatermark-ai/releases/tag/resources-2026-10-27) 包含两个数据分包与一个模型包，属于当日发布快照；当前固定集已在 10 月 29 日移除三张手写样本，不能把旧包直接视为当前清单，解压后先校验。查看报告不需要运行模型。

```bash
./start.sh setup       # 首次准备依赖与模型，可能需要联网
./start.sh check-data  # 核对当前固定集，不运行模型
./start.sh gui         # 打开桌面程序
```

日常处理使用已有本地依赖和模型。图片输入与参考答案分开，干净图、alpha 和标注不能用于决定当前单图的选区或结果。

2026-10-29 按用户要求，将纸面彩色阴影文字的分层反解接入普通默认处理，无需新开关或新模型。先沿用原检测入口，模型能拟合且未趋于不透明时按实际笔画反解，否则保留原阴影清理。已打开的旧窗口需重新启动、重新处理才生效。表格残影、正常彩色内容保护和耗时仍有问题；未完成全量放行或独立验证，不代表整体效果已达标。实际接入与验证见[默认接入记录](out/阴影分层默认接入_20261029_173436/阴影分层默认接入核对报告_20261029.html)。

## 怎样测试

```bash
./start.sh test --plan  # 先看本次实际修改需要检查什么
./start.sh test         # 按影响执行日常检查
./start.sh test-release # 发布或更新默认基线前做完整三模式对照
```

本机已有观察基线，日常沿用，不自动替换。初次在其他机器建基线时使用 `./start.sh freeze-baseline`，它只记录现状，包括缺陷。规则见 [放行门槛](config/regression_control.json) 和 [分层范围](config/regression_tiers.json)。

`./start.sh check-data` 只证明数据校验通过；`./start.sh eval` 和 `tools/run_min_regression.py --suite all` 只作固定集诊断，不能替代完整放行。桌面默认、桌面关闭笔画补全、CLI 默认的开关不同，比较时必须记录。

## 自动比较处理方法（试用）

程序先从同一原图的可见笔画、可读文字和直线交叠情况选择原方法或笔画补全，通常只修复一次。修复后检查越界、文字损失和共同痕迹；只有运行失败、越界，或另一方法有更充分依据时才补试一次。导出仅保存实际运行的方法，并注明未运行项及原因。仍不能确认被遮挡内容是否恢复正确；未达标或未知的结果不算成功。该提速候选默认关闭，单图验证不能替代完整放行。

```bash
./start.sh gui --experimental-auto-selection  # 单独试用入口；无需选择补全开关
.venv/bin/python -m wm.cli run 输入图片 --experimental-auto-selection --out out/自动比较试用
```

这是尚未完成完整放行与独立来源验证的候选，不替换普通启动的默认行为。本轮[十五分钟定向验证](out/自动效果选择改造_20261029_163154/十五分钟定向验证_20261029/自动效果选择_十五分钟最终对照_20261029.html)发现其他深色文字新增误选、部分候选超时；候选未通过，不建议作为默认处理。PDF结构处理优先；相同候选复用一次修复，所有检测、修复和比较计入总耗时。详细边界见[实际流程说明](docs/去水印处理流程图.md)。

[提速候选单图验证（2026-10-29）](out/自动选择提速单图验证_20261029_174300/自动选择提速单图验证_20261029.html)：冻结后仅测试用户深色大字图表，26项相关工程检查通过，但新旧两个实际运行均在210秒超时，未产生完整输出；本轮未通过，无法确认提速或图像效果，未调整代码重跑。其他样式、完整工程测试及独立验证未运行，默认入口不更新。

## 选区逐阶段追踪（独立诊断）

[2026年10月29日真实选区追踪与候选对照](out/选区逐阶段追踪_20261029_V2/选区逐阶段追踪与修复候选对照_20261029.html)：实际保存初始定位、补全、先验选择、修复入口、LaMa输入张量及实际修改像素。目标深色图表在补全阶段丢失10,676个真实笔画像素，之后到模型输入没有再丢失。边缘候选召回提高到99.21%，但数值被损伤，原9张中6张新增背景误选，未通过默认接入门槛。另一个正文风险策略保留完整检测并暂停生成，输出原图，明确为未自动修复。

本轮候选均为隔离工具，没有接入默认应用；原批次、跨样式探针与工程检查分别保留版本，不以测试通过或暂停处理冒充去水印成功。尚无独立泛化或完整发布放行结论，实际边界见长期流程说明。
