真实软件生成的 PDF

原文件完整保存。针对这两个已确认的受控导出件，逐页标记已知的“内部演示稿”文字对象，在相同导出版式下生成参考页和透明对象层；没有把原始 Letter 版与 A4 导出页直接当作逐像素对齐数据。

灰色水印为不透明灰字；黑色变体的对象不透明度约 84.71%。对象与正文共用内容流。原始字体导出编码影响文字提取，不能承诺与源 PDF 的 Unicode 提取结果完全相同。

PDF 掩码表示已知对象的渲染覆盖范围；alpha 包含字体抗锯齿覆盖和填充不透明度。不要把它理解成原应用导出的完整编辑图层。

拿到后怎么使用

解压后，先阅读 README.txt；JSONL 用于程序读取，UTF-8 CSV 用于表格筛选。默认读取器读取统一任务视图 129 条；严格配对视图保留原 121 条。

python scripts/load_manual_increment.py --root /解压目录 --limit 3
python scripts/load_manual_increment.py --root /解压目录 --kind pdf_page --limit 2
python scripts/validate_manual_increment.py --root /解压目录

图片输入、参考为 RGB uint8；mask 与 alpha 为单通道 uint8。训练时自行归一化到 0～1；PDF 页已提供 150 DPI 图像与原生 PDF 对象版本。weak_pairs.jsonl 和 references.jsonl 保留来源快照；其 8 个真实样本已按 training_tasks.jsonl 纳入相应训练任务。

可用表述：我们建立了图片与 PDF 可见水印训练数据集，结合已知参数的合成配对、真实软件 PDF 对象标注，并单列真实手写与应用导出辅助样本。
本轮新增 110 组合成图片正例、5 个负例、6 个真实软件 PDF 页面配对。

不能据此声称真实场景已经全部覆盖，也不能把未授权第三方下载图算成正式训练数据。
