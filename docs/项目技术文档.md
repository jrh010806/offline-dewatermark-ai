## 1. 项目概述

本系统为**招投标/政务文档**场景设计的智能去水印工具，核心能力是在**去除水印的同时保留原文档内容（文字、表格、印章、照片纹理）的完整性和可识别性**。

### 1.1 解决的问题

- 文档在分发过程中被叠印半透明水印（公司名、编号、密级标识等），影响阅读和二次使用
- 需要在本地离线环境中批量处理，不允许数据外传
- 处理后必须满足"非水印区域不变、水印区域不影响 OCR 识别"的刚性约束

### 1.2 设计原则

| 原则 | 实现方式 |
|---|---|
| 确定性优先 | 代数反混合为主通道，深度学习仅在必要时兜底 |
| 宁留残膜不伤文字 | 墨迹晕圈保护区强制置零 |
| 可验证 | 四条件判定协议，逐页输出量化报告 |
| 离线自洽 | 纯 CPU 可跑端到端，模型首次联网后缓存本地 |

## 2. 功能矩阵

> 本节按**水印样式**列能力边界；按**编号（WM-XXX）**的功能清单、逐条代码证据与状态口径，以 `docs/功能矩阵.md` 为唯一权威（48 条，M1–M8）。

### 2.1 支持的水印类型

| 水印样式 | 说明 | 处理能力 |
|---|---|---|
| `tiled_text` | 平铺斜向重复文字（如"内部资料 CONF-2026"，-30°） | 较好 |
| `big_center` | 大面积居中文（如"机密 T7009"，-35°） | 较好 |
| `dot_grid` | 规则点阵/网格图案 | 很好 |
| `corner_id` | 角落小编号（如"ZG-001-8F3A"） | 一般 |
| `heavy_dark` | 深色密集文字（如"禁止复制 NO-COPY"，强度 0.8） | 有限 |
| `diagonal_stripe` | 对角线条纹 | 一般 |
| PDF 独立透明图层水印 | 矢量 XObject，覆盖整页 | 很好（无损删除） |

### 2.2 支持的输入格式

| 格式 | 说明 |
|---|---|
| PDF | 结构图层引擎（引擎A）+ 栅格引擎（引擎B）双路由 |
| PNG / JPG / JPEG / BMP / TIFF | 栅格引擎直接处理 |
| 批量图片 | 多张图片作为同一文档的多页，自动启用跨页统计先验 |

### 2.3 输出

- 每页生成 `_clean.png`（去水印结果）和 `_watermark.png`（提取的透明水印层 RGBA）
- 逐页量化报告（JSON）：引擎、掩码来源、各项指标、通过/失败判定、耗时

### 2.4 不具备的能力（诚实边界）

| 场景 | 原因 |
|---|---|
| 深色重水印完全压住正文笔画 | 原色信息物理丢失，代数不可逆 |
| 照片/渐变/色块上的水印 | 无"纸面锚点"，算法主动放弃保护画面 |
| 不同尺寸/旋转页面的跨页估计 | 要求严格像素对齐 |
| 手写体水印 | 未在训练/合成集中覆盖 |
| 视频帧水印 | 仅处理静态图像 |

## 3. 系统架构

### 3.1 双引擎路由

```
输入文件
  │
  ├─ PDF? ──→ 结构探测（Engine A）
  │            ├─ 适用 → 删除水印 XObject → 无损输出
  │            └─ 不适用 ↓
  │
  └─ 栅格引擎（Engine B）
       ├─ 多页对齐 → 跨页统计先验 + 单页掩码
       └─ 单页 → 直方图尖峰检测
              │
              ↓
       掩码估计 → 修复 → 判定
```

### 3.2 处理流水线（栅格引擎）

```
┌─────────────────────────────────────────────────────────┐
│  1. 输入解码    PDF 渲染 200DPI / 图片读取               │
│  2. 去块滤波    JPEG 块效应门控（blocking ratio > 1.35） │
│  3. 水印定位    直方图尖峰 → 极点拟合 → 纸面锚点门       │
│  4. OCR 禁区    RapidOCR 识别正文区域，保护笔画          │
│  5. 方向滤波    Gabor 核检测斜向印章（实验性）            │
│  6. 跨页中值    多页逐像素中值分离水印与正文              │
│  7. 代数反混合  B = (I - β·t) / (1 - β·(1-s))           │
│  8. 墨晕保护    真实墨旁 3-5px 强制覆盖率为零            │
│  9. LaMa 重建   不透明核心区域（覆盖率 ≥ 0.97）深度学习   │
│ 10. 四条件判定  保真 / 残膜 / 识别 / 时限                │
└─────────────────────────────────────────────────────────┘
```

### 3.3 核心算法模型

**叠印物理模型：**

```
观测量 I = s·B + t
  其中 s = 1 - α₀（透明度互补）
       t = α₀·W（水印色贡献）
  目标：反解 B = (I - β·t) / (1 - β·(1-s))
```

**极点定位（直方图尖峰法）：**

- 被覆盖纸面极点：`s·P + t`
- 被覆盖墨迹极点：`t`
- 由 `α₀·(P - W) = m` 将强度绑定到颜色，仅一个自由参数用于打分搜索
- 用直方图**尖峰**（非分位数）定位，避免落入抗锯齿连续谱

**保护性规则：**

1. **纸面锚点门**：仅当同窗口内存在未覆盖纸面时才断言覆盖率
2. **墨晕保护**：距真实墨笔画 3-5px 内的像素优先级归文字（实测 83-91% 假阳性在此范围）
3. **不透明区域补充**：覆盖在墨上的不可测区域从纸侧同笔画传播填充

## 6. 质量保障体系

### 6.1 四条件判定协议

每页处理后自动评估四个维度：

| 条件 | 指标 | 阈值 | 含义 |
|---|---|---|---|
| **保真 (fidelity)** | mean_delta / p99_delta | ≤ 1.0 / ≤ 4.0 | 非水印区域像素变化极小 |
| **残膜 (residual)** | residual_coverage | ≤ 15% | 水印像素仍持有 ≥50% 残膜的比例 |
| **识别 (recognition)** | ink_iou | ≥ 0.90 | 输出笔画与真值 IoU（需有干净参照） |
| **时限 (time_budget)** | elapsed_ms | ≤ 120,000 ms | 单页 2 分钟内完成 |

### 6.2 失败编码

| 编码 | 触发条件 |
|---|---|
| NO_WATERMARK_DETECTED | 覆盖率 < 阈值，未找到水印 |
| RESIDUAL_WATERMARK | 残膜超标 |
| FIDELITY_BREACH | 非水印区像素变化过大 |
| RECOGNITION_REGRESSION | 笔画 IoU < 0.90 |
| REPAIR_FAILED | 修复异常 |
| STRUCTURE_NOT_APPLICABLE | PDF 结构引擎不适用 |
| OUT_OF_TIME_BUDGET | 超过 2 分钟时限 |
| NEEDS_MANUAL_MASK | 掩码置信度 < 0.12 |

### 6.3 合成数据集

由于客户未提供真实样本，系统自带**确定性合成数据集生成器**（随机种子固定 20261019），包含：

- 中文正文（宋体/黑体/微软雅黑渲染）
- 表格虚线、照片渐变块、红色印章等**不可删除内容陷阱**
- 5 种水印样式 × 逐页不同正文 × 同一水印（满足跨页先验前提）
- 支持 JPEG 压缩模拟（quality 参数）和噪声注入

## 7. 已知风险与限制

| 风险 | 影响 | 缓解状态 |
|---|---|---|
| PyMuPDF 为 AGPL-3.0（强传染开源许可） | 闭源商用需替换 | 计划迁移至 pypdfium2 (BSD) |
| 指标基于合成数据 | 真实效果未验证 | 需获取主办方真实样本重新标定阈值 |
| JPEG quality 75 下掩码精度从 0.90 降至 0.31 | 有损输入检测困难 | 已接入自适应去块滤波，实测有恢复 |
| 深色水印完全遮挡文字 | 代数不可逆 | LaMa 深度学习兜底（重建质量不保证） |
| 无 GPU 加速 | 大图单页处理可达数十秒 | 流式模式内存平坦；GPU 接入在路线图 |
| 跨页估计要求页面严格对齐 | 扫描歪斜/多尺寸失效 | 仅对齐批次启用，不对齐回退单页模式 |
| 交付机打包未验证 | PyInstaller/Nuitka 兼容性未知 | 需在目标机实测 |

## 9. 部署与使用

### 9.1 快速部署（新机器四条命令）

```bash
git clone https://github.com/jrh010806/offline-dewatermark-ai.git
cd offline-dewatermark-ai
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.lock
```

### 9.2 自检验证

```bash
python -c "import numpy, cv2, skimage, fitz, PySide6, PIL; print('依赖 OK')"
python -c "from wm.lama import is_available; print('LaMa:', '可用' if is_available() else '缺失，修复将报错（把模型放 models/）')"
python -m wm.cli synth --out data/syn
python -m wm.cli eval --data data/syn
```

### 9.3 使用方式

```bash
# 命令行处理单个文件
python -m wm.cli run input.pdf --out results/

# 打开桌面前端
python -m wm.app input.pdf

# 无头渲染（截图/演示）
python -m wm.app --shot output_dir/
```

### 9.4 LaMa 模型离线部署

在有网机器运行一次让模型自动下载，然后把以下任一位置的文件拷到目标机：

- `~/.cache/huggingface/hub/models--opencv--inpainting_lama/`（默认缓存）
- `models/inpainting_lama_2025jan.onnx`（项目根目录）
- 环境变量 `WM_LAMA_ONNX=/absolute/path/to/model.onnx`

## 附录 B：接口契约关键类型

```python
@dataclass(frozen=True)
class Thresholds:
    mask_alpha_min: float = 0.08        # 最低覆盖率阈值
    fidelity_mean_delta_max: float = 1.0  # 非水印区最大平均变化
    fidelity_p99_delta_max: float = 4.0   # 非水印区最大 p99 变化

    ink_iou_min: float = 0.90             # 笔画 IoU 下限

@dataclass
class MaskLayer:
    alpha: np.ndarray           # 逐像素水印覆盖率 [0,1]
    source: MaskSource          # 来源：structure/crosspage/prior/model/human
    confidence: float           # 检测置信度
    veil_strength: np.ndarray   # 叠印模型参数 s
    veil_offset: np.ndarray     # 叠印模型参数 t
    paper: np.ndarray           # 纸面亮度估计
    footprint: np.ndarray       # 二值水印足迹
```
